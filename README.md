# REIGN SYSTEM Discord Bot

بوت إدارة بسيط لأوامر التحذير والحظر والطرد والتايم أوت.

## التشغيل

1. انسخ `.env.example` إلى `.env` وضع توكن البوت ومعرف التطبيق. أضف `GUILD_ID` لتسجيل الأوامر في سيرفر تجريبي بسرعة.
2. ثبّت الاعتماديات:

   ```bash
   npm install
   ```

3. سجّل أوامر Slash:

   ```bash
   npm run deploy
   ```

4. شغّل البوت:

   ```bash
   npm start
   ```

## الأوامر

- `/warn user reason`: حفظ تحذير للعضو في `data/warnings.json`.
- `/ban user reason`: حظر العضو.
- `/kick user reason`: طرد العضو.
- `/timeout user duration reason`: تقييد العضو. المدة بصيغة `10m` أو `2h` أو `1d` وبحد أقصى 28 يومًا.

يمكن استخدام أوامر الإدارة كتابيًا أيضًا، مثل:

```text
باند @عمر 10d كان يخالف القوانين
طرد @عمر إزعاج الأعضاء
تايم اوت @عمر 20m مخالفة
تحذير @عمر مخالفة القوانين
فك تايم اوت @عمر
فتح روم #الدردشة
اغلاق روم #الدردشة
```

يمكن بدل المنشن كتابة ID العضو. مدة الباند المؤقت تُفك تلقائيًا بعد انتهاء المدة، أما الباند بدون مدة فيبقى دائمًا. يجب تفعيل `Message Content Intent` من Discord Developer Portal حتى يقرأ البوت الرسائل النصية.

يجب أن يملك البوت الصلاحيات المناسبة، وأن تكون رتبته أعلى من رتبة العضو المستهدف. فعّل `Server Members Intent` من Discord Developer Portal إذا احتجت لجلب الأعضاء.

## نظام المستوى

كل رسالة يرسلها العضو تمنحه `10 XP`. عند الوصول إلى الحد المطلوب للمستوى التالي يرسل البوت تلقائيًا. حسب النظام الحالي، الوصول من المستوى 1 إلى المستوى 10 يحتاج `4500 XP`، أي حوالي `450 رسالة`.

```text
مبارك @العضو، لقد ارتفع لفلك من (المستوى القديم) إلى (المستوى الحالي) استمر .
```

حدد روم إعلان ارتفاع المستوى في ملف `.env`:

```env
LEVEL_UP_CHANNEL_ID=معرف_روم_إعلانات_المستوى
```

يتم حفظ التقدم في `data/levels.json`، ولا تُحتسب رسائل البوت.

## تحديد الرتب المسموح لها

عدّل ملف `.env`، وضع IDs الرتب مفصولة بفواصل. لكل أمر سطر مستقل، مثل:

```env
COMMAND_BAN_ROLE_IDS=111111111111111111,222222222222222222
COMMAND_WARN_ROLE_IDS=333333333333333333
GAME_MAFIA_ROLE_IDS=444444444444444444
GAME_TICTACTOE_ROLE_IDS=444444444444444444
GAME_SHOOTING_ROLE_IDS=444444444444444444
```

الألعاب المتاحة هي: `CTWEET`, `FASTEST`, `FLAGS`, `WORDS`, `RPS`, و`SHOOTING`. ويمكن استخدام `GAME_ROLE_IDS` كرتبة عامة لكل الألعاب. اترك سطر أي أمر فارغًا ليعتمد على صلاحيات Discord الأصلية. أصحاب `ADMINISTRATOR`، والمستخدمون في `ADMIN_USER_IDS`، والرتب في `ADMIN_ROLE_IDS` يستطيعون استخدام كل شيء.
